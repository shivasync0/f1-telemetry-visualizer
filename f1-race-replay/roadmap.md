# F1 Race Replay Roadmap

Since launching this project, I've receieved a lot of feedback and feature requests from the community. I thought it would be helpful for everyone (including myself) to have a clear vision and roadmap for the future of this project, so if you are planning on contributing or using it, you know what to expect.

## Performance Enchancements & User Experience Improvements

This project is growing quite quickly, which is fantastic, but is also means that its really easy to overlook performance and user experience optimizations. Some of the key areas I want to focus on include:
- **Reducing Lag during race replay:** Rendering some of the UI elements is starting to cause noticeable lag during race replays, especially on lower-end devices. I want to optimize the rendering process to ensure a smooth experience for all users. (I have already started on this, but there's more work to be done)
- **De-cluttering the UI:** As more features are added, the UI is starting to feel a bit overwhelming. I think it would be great to add better toggle options or preset view types to help usesrs focus on the data that matters most to them. This would also allow us to add more insights on the race replay without being limited by just the available screen space.
 

## Your Contributions

If you would like to get involved with this project and help bring these features to life, please do feel free to reach out or submit a pull request. Your contributions are highly valued and will help shape the future of this project.

# Contribution Guidelines

To ensure a smooth collaboration process, please follow these guidelines when contributing to the project:
- **Open Issues:** If you find a bug or have a feature request, please open an issue on GitHub with a clear description and any relevant details.
- **Choosing what to build**: Feel free to pick any open issue that interests you. If you want to work on a new feature, please discuss it in an issue first or review the roadmap to ensure it aligns with the project's goals.
- **Pull Requests:** When submitting a pull request, please ensure your code only includes changes related to the issue or feature you are addressing. Include a clear description of the changes made and reference the related issue. Also, if your change relates to any visual elements, please include screenshots, GIFs or screen recordings to illustrate the updates.
- **Pull Request Discussions**: Be open to feedback and discussions on your pull requests. Constructive criticism is welcome and helps improve the quality of the project. If you are commenting on someone else's pull request, please be respectful and considerate in your feedback. Always ensure that your feedback is in line with the project's goals and guidelines, rather than personal preferences.
